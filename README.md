# The Code² — Portfolio

Site portfolio professionnel (Next.js 15, React 19, Tailwind CSS).

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3010](http://localhost:3010).

## Personnalisation

Modifier textes, projets, e-mail et liens dans **`lib/content.ts`**.

Logo : remplacer `public/logo.jpg`.

## Build production

```bash
npm run build
npm start
```

Déploiement recommandé : [Vercel](https://vercel.com) (import du dossier `portfolio`).
